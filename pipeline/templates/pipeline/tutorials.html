Everything you need to prepare your data for RNAseek
 File Format Guide

Accepted Raw Read Formats

RNAseek accepts .fq.gz or .fastq.gz (compressed FASTQ) files. You must upload at least two experimental groups (e.g., 3 Control + 3 Treatment samples) for statistical testing to be valid.

Uncompressed .fastq or .fq files are not accepted. Please gzip your files before uploading.

Paired-End Reads

If your experiment uses paired-end sequencing, ensure filenames follow the standard convention: SampleName_R1.fq.gz and SampleName_R2.fq.gz. The system auto-detects read pairs, but you can also manually toggle Paired-End mode during setup.

 Metadata Mapping Guide

Condition Mapping (Required)

Every uploaded sample must be assigned to a biological condition for the statistical contrast. You can map conditions interactively in the Setup Wizard or upload a .csv file.

Filename Condition Batch ID (optional) Timepoint (optional)
WT_rep1_R1.fq.gz Control Batch_1 Day 0
WT_rep2_R1.fq.gz Control Batch_1 Day 0
KO_rep1_R1.fq.gz Treated Batch_2 Day 7
KO_rep2_R1.fq.gz Treated Batch_2 Day 7

Batch ID – If provided, triggers automatic ComBat-seq batch correction in Stage 2.

Timepoint – If provided, switches DESeq2 to the Likelihood Ratio Test (LRT) for time-series analysis.
